# Исходники

- `mockup-desktop-1440.png` — полностраничный рендер десктопного фрейма макета
  (1440×10183). Эталон для попиксельной сверки, используется скриптами в `../../_tools/`.
- `bulk/` — оригиналы фотографий, загруженные дизайнером в Figma, в полном разрешении.
  На сайте используются не они, а экспорты узлов из `../img/` (обрезаны по боксам макета).
  Держим на случай, если понадобится другой кроп.
